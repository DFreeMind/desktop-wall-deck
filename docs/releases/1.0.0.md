# 桌面壁纸 1.0.0

**桌面壁纸（Wall Deck）1.0.0 正式版现已发布。** 本版本面向 Windows x64 桌面环境，提供本机壁纸整理、多显示器投放、在线图片发现与缓存管理的一体化工作台。

## 下载

- [桌面壁纸安装程序（desktop-wall-deck_1.0.0_x64-setup.exe）](https://github.com/DFreeMind/desktop-wall-deck/releases/download/v1.0.0/desktop-wall-deck_1.0.0_x64-setup.exe)：标准安装包。
- [桌面壁纸免安装版（desktop-wall-deck_1.0.0_x64.exe）](https://github.com/DFreeMind/desktop-wall-deck/releases/download/v1.0.0/desktop-wall-deck_1.0.0_x64.exe)：下载后直接运行，仍使用应用数据目录保存索引与缓存，需要系统安装 WebView2 Runtime。

## 主要功能

- **选择和应用分开**：单击壁纸只选择待应用图片；打开大图可查看细节、缩放和切换图片。预览不会修改桌面。将图片拖到拓扑中的目标屏幕，悬停时查看预览，松手后应用到该屏。
- **多显示器自动适配**：按系统检测到的显示器位置和尺寸绘制真实拓扑，并根据窗口空间自动缩放整组屏幕。支持按屏幕分别设置、应用到全部显示器，以及按各屏几何位置裁切的跨屏拼接。拓扑变化后会重新枚举并尝试按显示器身份恢复绑定。
- **本机图库与合集**：索引已有文件夹中的静态图片，原图留在原目录；支持搜索、收藏、排序、多级合集、来源扫描和缺失文件重新定位。
- **在线图片发现**：通过公开接口搜索 Wallhaven、NASA 影像与维基共享资源，可分页浏览并下载入库。来源、作者和许可信息随作品记录保存。
- **预览、主题与缓存管理**：原图按需读取；提供多种主题色、背景点缀、缩略图修复和闲置派生缓存清理，并分别查看原文件索引与应用缓存占用。

## 系统要求与支持范围

- Windows x64。
- 支持静态图片壁纸；不支持视频或 HTML 动态壁纸。
- 在线图库是否能访问取决于网络和来源服务状态。
